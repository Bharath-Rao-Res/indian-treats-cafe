# The Indian Treats Cafe — Madurai ☕🍽️

> **Where Every Bite Feels Like Home**  
> A modern, premium, fully responsive restaurant and cafe website inspired by the warm, cozy, and vibrant dining atmosphere of **The Indian Treats Cafe** in Madurai, Tamil Nadu.

---

## 🌟 Highlights & Features

- **Cozy Indian Cafe Aesthetic:** Warm coffee brown, terracotta, beige, cream, and muted gold palette with subtle Indian mandala motifs and warm ambient lighting.
- **Dynamic Food Menu:** Categorized food cards (*Burgers, Chicken, Pasta, Snacks, Beverages, Desserts*) with real-time search, dietary filters (Veg / Non-Veg), and detail modals.
- **Signature Platter Showcase:** Dedicated spotlight on *The Indian Treats Special* with ingredient breakdown and quick ordering.
- **Interactive Cart & WhatsApp Checkout:** Full-featured cart drawer supporting Dine-in (with table number), Takeaway, and Delivery with 1-click WhatsApp order formatting.
- **Masonry Gallery & Lightbox:** Visual showcase with category filters and fullscreen photo lightbox.
- **Google Reviews Integration:** Highlighting verified 5.0 ★ customer ratings and testimonials with direct Google Maps review links.
- **Location & Easy Contact:** Interactive Google Maps embed, click-to-call, and one-click copyable Madurai address with feedback.
- **Mobile-First UX:** Sticky bottom quick action bar (*Call, Menu, Order*) and responsive touch drawer navigation.
- **SEO & Schema.org:** Local business `CafeOrCoffeeShop` JSON-LD structured data for search engine optimization.

---

## 🛠️ Tech Stack

- **Framework:** [React](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Language:** TypeScript
- **Styling:** Tailwind CSS + Custom CSS Variables & Animations
- **Icons:** [Lucide React](https://lucide.dev/)
- **Interactive Effects:** Canvas Confetti

---

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```
Visit `http://localhost:5173/` in your browser.

### 3. Build for Production
```bash
npm run build
```
